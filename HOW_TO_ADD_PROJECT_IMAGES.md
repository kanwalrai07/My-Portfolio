# How to Add Project Images

## Image Requirements
- **Format**: JPG, PNG, or WebP
- **Recommended Size**: 800x600 pixels (or similar 4:3 aspect ratio)
- **File Size**: Keep under 500KB for fast loading
- **Quality**: High quality, clear screenshots or photos

## Step-by-Step Instructions

### 1. Prepare Your Images
Take screenshots or prepare images for each project:
- **Library Management System** → `library-management-system.jpg`
- **Car Fixers Website** → `car-fixers-website.jpg`
- **Car Parking System** → `car-parking-system.jpg`
- **Inventory Management (Cloud)** → `inventory-management-cloud.jpg`
- **Campus Network System** → `campus-network-system.jpg`
- **Student Management System** → `student-management-system.jpg`

### 2. Add Images to the Project
1. Open the `images` folder in your project directory
2. Copy your project images into the `images` folder
3. Make sure the file names match exactly:
   - `library-management-system.jpg`
   - `car-fixers-website.jpg`
   - `car-parking-system.jpg`
   - `inventory-management-cloud.jpg`
   - `campus-network-system.jpg`
   - `student-management-system.jpg`

### 3. Verify Images Are Working
1. Open `projects.html` in your browser
2. Check that all project images display correctly
3. If an image is missing, a placeholder will appear automatically

## Image Optimization Tips

### Using Online Tools:
- **TinyPNG** (https://tinypng.com/) - Compress images without losing quality
- **Squoosh** (https://squoosh.app/) - Resize and optimize images
- **Canva** (https://www.canva.com/) - Create professional project mockups

### Screenshot Tips:
- Use full-screen screenshots of your applications
- Capture the most impressive/important features
- Use consistent styling across all project images
- Consider adding a subtle border or shadow for a professional look

## Alternative: Use Placeholder Images
If you don't have images yet, you can use placeholder services:
- **Placeholder.com**: `https://via.placeholder.com/800x600/ff00ff/00ffff?text=Project+Name`
- **Unsplash**: Free high-quality stock photos
- **Pexels**: Free stock photos
